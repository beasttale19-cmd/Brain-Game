# BRAIN GAME 🧠

Brain Game is a fun and interactive web game where players solve riddle-like questions and tricky challenges. The game is made to test thinking skills, creativity, and problem-solving ability. Every level contains different types of questions that may look simple at first but require careful thinking to solve correctly.

The website contains multiple pages connected together to create a complete game experience. Players can move through levels, get help if they are stuck, and explore different sections of the website. The project was created as a fun learning experience while also improving web dev skills.

---

# Features

* Riddle-like brain games
* Tricky and fun questions
* Different levels and challenges
* Multiple connected pages

---

# Pages Included

## 🎮 Game Page

The Game page is the main part of the website where players can play different types of brain games and solve tricky questions. Each level contains unique challenges that test the player’s thinking and problem-solving skills.

Players must carefully think before answering because some questions are designed to confuse or trick the player.

---

## ❓ Help Page

The Help page allows users to get help if they are unable to complete any level. A video solving all the levels is available on this page so players can watch it and understand the correct answers whenever they get stuck.

This page was added to help users continue the game without feeling completely stuck on difficult levels.

---

## 📞 Contact Us Page

The Contact Us page is a demo page that shows how a contact page looks on a real website. It was added to make the project feel more complete and realistic.

This page demonstrates a simple contact section that users may find in many websites.

---

## ✅ Ans Page

The Ans page appears after completing each level. It shows the result after solving a question and helps the player move forward in the game.

This page was added to create a better game flow and make level progression feel more interactive.
