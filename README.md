#BRAIN GAME

Brain game is a game where we can play riddle-like games where we solve questions. The questions are tricky questions.

The pages of the web game are:
-Game -> different types of games are given.
-Help -> You can get help. There is a video solving all levels. It can be watched if you cant complete any level
-contact us -> A demo page of contact us where we can know how a contact us page look like.
-Ans - the page which comes after completeing each level.
